# 🤖 Robo Speaker

Robo Speaker is a simple Python-based text-to-speech application that converts user-provided text into speech using the pyttsx3 library.

## ✨ Features

- Converts text into speech.
- Accepts continuous user input.
- Speaks the entered text.
- Supports a quit command.
- Provides a goodbye message when exiting.

## 🛠️ Technologies Used

- Python
- pyttsx3

## 📦 Installation

Install the required library:

```bash
pip install pyttsx3
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Install the required dependency.
4. Run:

```bash
python main.py
```

## 🎮 How to Use

1. Run the program.
2. Enter the text you want the robot to speak.
3. The application will convert your text into speech.
4. Enter `q` to quit the application.
